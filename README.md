# Автотесты для «Яндекс.Самоката»

Это учебный проект шестого спринта. Тесты написаны на Python с помощью
Selenium и pytest. Для отчётов используется Allure.

В проекте проверяется:

- раздел «Вопросы о важном»;
- оформление заказа с двумя наборами данных;
- верхняя и нижняя кнопки «Заказать»;
- переход по логотипу Самоката;
- переход по логотипу Яндекса.
